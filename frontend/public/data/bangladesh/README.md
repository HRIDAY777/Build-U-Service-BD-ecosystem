locations.json retains names, aliases, IDs and parent-child hierarchy from the
source dataset, excluding coordinates, inferred postcodes and delivery zones.
This community dataset is not an official or guaranteed complete register.
Villages are not included. New/missing localities can be entered manually.
Dataset coverage does not enable service/delivery coverage.
